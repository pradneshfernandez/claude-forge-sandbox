## Objective
`examples/todo-cli/todo.py` exists: the argparse CLI and only `__main__` entry point. It
parses argv, loads via `storage`, dispatches to `core`, saves via `storage`, prints output,
and returns the correct exit code. This is the integration layer wiring the two modules
built in T-008 and T-009.

## Instructions
Implement `examples/todo-cli/todo.py` (Python 3.11, stdlib only: `argparse`, `sys`).
Import the sibling modules with `import core` and `import storage` (they resolve because
the package dir is on `sys.path` under unittest discovery and when run as a script).

1. Build an `argparse.ArgumentParser` with four subparsers (`dest="cmd"`, required):
   - `add` → one positional arg `text` (str).
   - `list` → no args.
   - `done` → one positional arg `id` with `type=int`.
   - `rm` → one positional arg `id` with `type=int`.
2. Define `def main(argv: list | None = None) -> int:` that:
   - Parses `argv` (default `sys.argv[1:]`).
   - Computes `path = storage.resolve_path()` and `todos = storage.load(path)`.
   - Dispatches:
     - `add`: `todos, new_id = core.add_todo(todos, args.text)`; `storage.save(path, todos)`;
       `print(new_id)`; return 0.
     - `list`: `out = core.format_list(todos)`; if `out` is non-empty `print(out)`; return 0.
       (Do NOT save on list.)
     - `done`: `core.mark_done(todos, args.id)`; `storage.save(path, todos)`; return 0.
     - `rm`: `core.remove_todo(todos, args.id)`; `storage.save(path, todos)`; return 0.
3. Error mapping (print message to `sys.stderr`, return the exit code — do NOT raise past main):
   - `ValueError` from `core.add_todo` (empty text) → stderr message, return 1.
   - `KeyError` from `core.mark_done` / `core.remove_todo` (missing id) → stderr message
     like `f"error: no todo with id {args.id}"`, return 1.
   - `storage.CorruptStoreError` → stderr message, return 2.
4. At bottom: `if __name__ == "__main__": sys.exit(main())`.

## Acceptance criteria (each must be mechanically checkable)
- [ ] `main(["add", "buy milk"])` prints the new id, writes the store, returns 0
- [ ] `main(["list"])` prints `1 [ ] buy milk` style lines and returns 0; empty store prints nothing, returns 0
- [ ] `main(["done", "1"])` sets that todo done and returns 0; unknown id → stderr + returns 1
- [ ] `main(["rm", "1"])` removes it and returns 0; unknown id → stderr + returns 1
- [ ] `main(["add", "   "])` → stderr + returns 1 (empty text), store unchanged
- [ ] A corrupt store surfaced as `CorruptStoreError` → stderr + returns 2
- [ ] `todo.py` uses `type=int` for the `done`/`rm` id args (bad id string → argparse error)
- [ ] Full round-trip (add → list → done → list → rm → list) works via a `TODO_FILE` temp path
- [ ] All criteria covered by tests in `examples/todo-cli/tests/test_todo.py`
