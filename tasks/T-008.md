## Objective
`examples/todo-cli/core.py` exists: a pure, I/O-free module operating over an in-memory
list of todo dicts. It has NO filesystem access and does NOT import `json` or `storage`.
A todo is a plain dict of exact shape `{"id": int, "text": str, "done": bool}`.

- SPEC.md §Data model (lines 64–80) — todo shape, id allocation, text rules

## Instructions
Implement `examples/todo-cli/core.py` with these EXACT function signatures (Python 3.11,
stdlib only, no imports needed beyond typing if you want them):

1. `def add_todo(todos: list, text: str) -> tuple:`
   - Strip `text`. If the stripped result is empty, raise `ValueError` (caller maps to exit 1).
   - New id = `max((t["id"] for t in todos), default=0) + 1`.
   - Append `{"id": <new id>, "text": <stripped text>, "done": False}` to a copy or to
     `todos` in place, then RETURN a 2-tuple `(todos, new_id)` where `todos` is the updated
     list and `new_id` is the int id assigned. (Return the same list object you mutated.)

2. `def mark_done(todos: list, todo_id: int) -> list:`
   - Find the todo whose `id == todo_id`. If none, raise `KeyError(todo_id)` (caller → exit 1).
   - Set its `done = True`. Return the list.

3. `def remove_todo(todos: list, todo_id: int) -> list:`
   - If no todo has `id == todo_id`, raise `KeyError(todo_id)` (caller → exit 1).
   - Remove that todo. Return the list.

4. `def format_list(todos: list) -> str:`
   - Return one line per todo, joined by `"\n"`, each formatted EXACTLY as:
     `f"{id} [ ] {text}"` when not done, `f"{id} [x] {text}"` when done.
   - For an empty list, return the empty string `""`.

Raise the specified exceptions; do NOT print, do NOT call `sys.exit`, do NOT touch files.

## Acceptance criteria (each must be mechanically checkable)
- [ ] `add_todo([], "buy milk")` returns `([{"id":1,"text":"buy milk","done":False}], 1)`
- [ ] `add_todo` on a list with ids {1,3} assigns id 4 (max+1), not 2
- [ ] `add_todo(todos, "   ")` raises `ValueError`
- [ ] `mark_done` on a missing id raises `KeyError`; on a present id sets `done=True`
- [ ] `remove_todo` on a missing id raises `KeyError`; on a present id removes exactly that item
- [ ] `format_list` produces `"1 [ ] a\n2 [x] b"` for those two todos; `""` for `[]`
- [ ] core.py imports neither `json` nor `storage` nor any third-party package
- [ ] All criteria covered by tests in `examples/todo-cli/tests/test_core.py`

## Non-goals — do NOT
- Do NOT import `json`, `os`, `storage`, or read/write any file
- Do NOT call `print()` or `sys.exit()` — raise exceptions instead
- Do NOT reuse ids of deleted todos within the same list (max+1 only)
- Do NOT create storage.py, todo.py, or any test file
- Do NOT add any third-party dependency
