## Objective
Add an `edit` subcommand: `todo edit <id> "<new text>"` replaces an existing todo's
text without touching its `done` state. This is the first post-dry-run feature,
added specifically to produce a real, measured `/execute-wave` (see docs/telemetry.md
§Per-wave log — this wave's row is what we're generating).

## Context (read these, nothing else)
- SPEC.md §Functional scope (the `edit` bullet, added this wave)
- examples/todo-cli/core.py — imitate `mark_done`'s shape exactly (lookup by id,
  mutate in place, raise `KeyError(todo_id)` if absent) and `add_todo`'s text
  validation (`.strip()`, raise `ValueError` if empty)
- examples/todo-cli/todo.py — imitate the `done` subcommand's argparse + dispatch +
  error-mapping shape

## Instructions
1. In `core.py`, add:
   `def edit_todo(todos: list, todo_id: int, text: str) -> list:`
   - Look up the todo by id (same loop pattern as `mark_done`).
   - If not found: `raise KeyError(todo_id)`.
   - Strip `text`; if empty after stripping: `raise ValueError("Text cannot be empty")`.
   - Set `todo["text"] = stripped` (leave `done` untouched). Return `todos`.
   - Order of checks: validate text emptiness only after confirming the id exists
     (matches acceptance criteria below).
2. In `todo.py`:
   - Add an `edit` subparser: positional `id` (`type=int`), positional `text` (`type=str`).
   - Dispatch branch: call `core.edit_todo(todos, args.id, args.text)`; on success
     `storage.save(path, todos)`, return 0. On `KeyError`: stderr
     `f"error: no todo with id {args.id}"`, return 1 (same message shape as `done`/`rm`).
     On `ValueError` from `core.edit_todo`: stderr `f"error: {e}"`, return 1 (same shape
     as `add`). Do NOT save on either error path.

## Acceptance criteria (each must be mechanically checkable)
- [ ] `core.edit_todo` replaces `text` for a matching id, leaves `done` unchanged, returns the same list object mutated
- [ ] `core.edit_todo` on missing id raises `KeyError`
- [ ] `core.edit_todo` on empty/whitespace-only text (existing id) raises `ValueError`
- [ ] `core.edit_todo` strips leading/trailing whitespace from the new text
- [ ] `main(["edit", "1", "new text"])` updates the store and returns 0
- [ ] `main(["edit", "99", "x"])` (missing id) → stderr + returns 1, store unchanged
- [ ] `main(["edit", "1", "   "])` (empty text, existing id) → stderr + returns 1, store unchanged
- [ ] All criteria covered by tests in `examples/todo-cli/tests/test_core.py` and `examples/todo-cli/tests/test_todo.py`

## Non-goals — do NOT

- Do NOT allow `edit` to change `done` state
- Do NOT add any third-party dependency
- Do NOT create or edit test files (owned by the test-writer)
