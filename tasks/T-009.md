## Objective
`examples/todo-cli/storage.py` exists: the ONLY module that touches the filesystem and
`json`. It resolves the store path, loads a validated list of todo dicts (failing closed
on corruption), and saves atomically. It does NOT import `core`.

## Instructions
Implement `examples/todo-cli/storage.py` (Python 3.11, stdlib only: `os`, `json`,
`tempfile` allowed) with these EXACT signatures. Define a module-level exception
`class CorruptStoreError(Exception): pass` used to signal corruption (caller maps to exit 2).

1. `def resolve_path() -> str:`
   - Return `os.environ["TODO_FILE"]` if that env var is set and non-empty.
   - Otherwise return `os.path.join(os.path.expanduser("~"), ".todo-cli", "todos.json")`.

2. `def load(path: str) -> list:`
   - If the file does not exist, return `[]` (missing store ⇒ empty).
   - Read the file text. If it is empty or whitespace-only, return `[]`.
   - Parse with `json.loads`. On `json.JSONDecodeError`, raise `CorruptStoreError`.
   - Validate: the top level MUST be a `list`; every item MUST be a `dict` with EXACTLY
     the keys `{"id","text","done"}` where `type(id) is int`, `type(text) is str`,
     `type(done) is bool`. Note `bool` is a subclass of `int`; check `done` with
     `isinstance(done, bool)` and `id` with `isinstance(id, int) and not isinstance(id, bool)`.
     Any violation ⇒ raise `CorruptStoreError`.
   - On success return the list of dicts unchanged.

3. `def save(path: str, todos: list) -> None:`
   - Ensure the parent directory exists: `os.makedirs(os.path.dirname(path), exist_ok=True)`
     (guard against an empty dirname — if `os.path.dirname(path)` is `""`, skip makedirs).
   - Write atomically: create a temp file in the SAME directory as `path` via
     `tempfile.mkstemp(dir=<parent dir>)`, write `json.dumps(todos, indent=2)` plus a
     trailing newline to it, flush+close, then `os.replace(tmp, path)`.
   - On any exception after the temp file is created, remove the temp file before re-raising.

Do NOT use `shell=True`, `eval`, `exec`, or `pickle`. Do NOT import `core`.
Do NOT call `sys.exit` or `print` — raise `CorruptStoreError` / propagate OSError; the CLI maps them.

## Acceptance criteria (each must be mechanically checkable)
- [ ] `resolve_path()` returns `$TODO_FILE` when set, else `~/.todo-cli/todos.json`
- [ ] `load()` on a nonexistent path returns `[]`

- [ ] `load()` on invalid JSON raises `CorruptStoreError`

- [ ] storage.py does not import `core`

## Review findings

**Code review: CHANGES (2026-07-13)**

- `storage.py:100` — Bug: `tempfile.mkstemp(dir=parent_dir if parent_dir else None)`.
  When `path` has no directory component (`os.path.dirname(path) == ""`, e.g. a
  relative `TODO_FILE=todos.json`), this falls back to `dir=None`, which places the
  temp file in the system temp dir instead of cwd. `tempfile.mkstemp(dir="")` already
  correctly resolves to cwd. The `None` fallback violates the spec's "temp file in the
  SAME directory as path" requirement and can raise `OSError: Invalid cross-device
  link` from `os.replace()` if `/tmp` and cwd are on different filesystems — defeats
  the atomic-write guarantee for this edge case.
  **Fix:** pass `dir=parent_dir` directly (drop the ternary), or `dir=parent_dir or "."`.
- Minor, non-blocking: `resolve_path()` (`storage.py:17`) does
  `os.environ.get("TODO_FILE", "").strip()`, treating a whitespace-only `TODO_FILE` as
  unset. Spec only says "set and non-empty" — stripping is unrequested behavior. Low
  risk; either revert to a plain non-empty check or leave as-is (reviewer's call, not
  blocking).

**Security review: APPROVE** — deserialization, path handling, and atomic-write
pattern all sound within the stated local-only threat model. No blocking findings.
